# Lecture Studio 사용 안내

Windows에서 Canvas 강의와 마이크 녹음을 로컬 Whisper로 전사하고 TXT로 저장합니다. AI API 키는 필요 없습니다. 학교 공식 프로그램은 아닙니다. 그림 안내는 **START_HERE.html**을 여세요.

## 새 PC 설치

1. [Python 3.11 64-bit와 Launcher](https://www.python.org/downloads/windows/)를 설치합니다. `py -3.11 --version`으로 확인합니다.
2. `install_ffmpeg_windows.bat`를 실행합니다. WinGet 설치가 안 되면 [FFmpeg 공식 다운로드](https://ffmpeg.org/download.html)의 Windows 빌드에서 `ffmpeg.exe`와 `ffprobe.exe`가 있는 bin 폴더를 사용자 환경 변수 Path에 추가합니다.
3. 설치 창과 터미널을 닫았다가 다시 엽니다.
4. `setup_windows.bat`를 실행합니다. NVIDIA GPU는 1, CPU는 2를 선택합니다.
5. 환경 검사 결과를 확인한 뒤 `start_windows.bat`를 실행합니다.

Setup은 `.venv`와 Torch·Whisper·Qt·PDF 처리·마이크 입력·Chromium을 설치합니다. 첫 전사 때 Whisper 모델을 다운로드합니다. 새 PC에는 기존 `.venv`를 복사하지 말고 다시 설치하세요. GPU 고정 설치 조합은 Torch 2.8.0 / CUDA 12.8 wheel입니다. 호환 NVIDIA 드라이버가 필요하며 GPU 호환성 문제는 CPU로 전환해 사용할 수 있습니다.

PDF/PPTX는 별도 Office가 필요 없습니다. 구형 PPT는 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/)를 설치하거나 PPTX/PDF로 변환해 사용합니다.

## 학교 연결과 로그인

첫 실행 안내 또는 **학교 · 계정 설정**에서 학교 Canvas 주소를 입력합니다. 경북대는 `https://canvas.knu.ac.kr`이며 SSO 주소 `appfn.knu.ac.kr/login.knu`를 입력하는 것이 아닙니다. 다른 학교는 과목 화면의 Canvas 기본 주소를 입력하세요.

**수동 로그인 사용**이 기본입니다. 학교 브라우저에서 로그인 후 과목 화면이 보이면 앱의 **로그인 완료 · 계속**을 누릅니다. 화면에서 로그인 상태를 확인하면 자동으로 진행하기도 합니다. 기존 로그인 세션은 재사용합니다. 자동 입력을 선택해도 외부 SSO·추가 인증은 수동으로 처리할 수 있습니다.

토큰은 **학교 LMS → 계정 → 설정 → 새 액세스 토큰 → 토큰 발급** 순서로 발급받아 붙여넣습니다. 학교 정책에 따라 토큰 발급/API 사용이 제한될 수 있습니다. 주소 변경 시 이전 학교의 토큰·계정 입력은 비워집니다.

로그인 유지를 켜면 계정 정보는 Windows DPAPI로 암호화해 `%LOCALAPPDATA%\KnuLectureTranscriber`에 저장합니다. 학교별 브라우저 프로필은 일반 Chrome과 별개입니다. 다른 PC에서는 계정을 다시 등록하세요. **로그아웃**은 저장 계정과 현재 앱 브라우저 세션을 지우며 MP4/TXT는 보존합니다. 학교 서버의 토큰 자체를 폐기하지는 않습니다.

학교 연결 없이 녹음·로컬 전사만 사용할 때는 시작 안내의 **나중에 · 로컬 사용**을 누르세요.

## 강의 전사

1. 과목 선택 → **영상 목록 불러오기** → 원하는 영상 체크.
2. 필요하면 PDF/PPT 참고자료 추가.
3. 모델·장치·언어·저장 폴더 확인 → **선택 영상 전사**.
4. 다운로드와 전사가 끝나면 **완료된 파일**에서 결과 확인.

장치 auto는 CUDA를 사용할 수 있으면 GPU, 아니면 CPU를 선택합니다. GPU 사용 중 오류가 나면 CPU로 자동 재시도하지 않으므로 직접 변경하세요. 언어 auto는 영상 앞부분으로 주 언어를 판단합니다. 한국어 강의는 ko로 지정할 수 있습니다.

숨김 브라우저로 영상 주소를 찾으며 필요할 때 로그인/재생 요청을 표시합니다. 수동 로그인 후에는 현재 세션을 유지하기 위해 해당 브라우저가 보일 수 있습니다. 재생 버튼을 누르면 약 3분 동안 주소를 확인합니다. 중지할 수 있으며 네트워크 응답에 따라 대기는 길어질 수 있습니다.

다른 학교는 Canvas 표준 API와 노출된 MP4 범위를 지원합니다. 모듈의 외부 도구·페이지·링크는 후보이며 일반 웹페이지가 포함될 수 있습니다. HLS 전용·DRM·학교별 외부 서비스 전체는 지원하지 않습니다. 경북대는 빨강, 다른 학교는 주소별 파랑·보라·청록 테마를 적용하며 공식 교색을 조회하지는 않습니다. 접속·재생은 학교 시스템에 기록될 수 있고 출석을 보장하지 않습니다.

## 마이크 녹음

**마이크 녹음 → 장치 선택 → 녹음 시작 → 녹음 종료 · 저장** 순서입니다. 시간·입력 레벨을 표시하며 종료 후 MP3 저장과 전체 TXT 전사를 진행합니다. 녹음 중 자막은 표시하지 않습니다. 자동 전사를 끄면 녹음만 저장하고 나중에 전사할 수 있습니다.

Windows 마이크 접근과 데스크톱 앱 접근을 허용하세요. 기본 기능은 마이크 입력이며 시스템 소리 루프백은 별도로 제공하지 않습니다. 시스템이 스테레오 믹스나 가상 입력 장치를 제공하면 목록에서 선택할 수 있습니다.

새 녹음의 저장 구조:

```text
선택한 저장 폴더/
  녹음결과/
    녹음_날짜_시간_고유번호/
      녹음_날짜_시간_고유번호.txt
      오디오/  ← MP3와 복구용 WAV
      _관리정보/  ← 용어·완료 상태 JSON
```

본문 TXT는 한 개입니다. 녹음은 WAV에 계속 기록하고 종료 후 MP3로 변환하며 WAV도 보존합니다. 실패 시 남은 WAV를 **내 영상 추가**로 전사할 수 있습니다. 로컬 녹음은 1초 이상, LMS에서 받은 영상은 대기 영상 방지를 위해 10초 이상만 전사합니다.

LMS 결과는 과목별 `videos`와 `transcripts`에 저장합니다. 참고자료의 추출 용어는 Whisper 힌트로 쓰며 인식을 보장하지 않습니다. 스캔 자료는 OCR을 하지 않습니다.

## 완료된 TXT 관리

- **전체 결과 / 마이크 녹음** 필터와 이름 검색으로 찾습니다.
- **TXT 이름 변경**은 실제 파일과 완료 기록을 갱신합니다. 재전사해도 새 이름을 유지합니다.
- **파일 위치 열기**는 선택한 TXT의 폴더를 엽니다. **녹음 저장소 열기**는 녹음결과 폴더를 엽니다.
- **TXT 삭제**는 확인 후 선택한 본문 TXT를 휴지통으로 옮기고 목록에서 제거합니다. MP3·WAV·참고자료는 보관합니다. 휴지통 이동이 불가능하면 삭제하지 않고 실패를 안내합니다.
- 파일이 이미 없으면 목록에서만 제거할 수 있습니다. 작업 진행 중에는 이름 변경/삭제를 사용할 수 없습니다.
- 삭제 후 다시 전사를 실행하면 TXT를 새로 생성합니다. `_관리정보`는 이름 유지와 재전사 관리를 위해 보관합니다.

이전 버전의 보조 TXT/JSON은 자동 삭제·이동하지 않습니다. 새 결과부터 정리된 구조를 사용합니다. 휴지통에서 복원한 TXT는 파일 자체는 복원되지만 앱 목록에 자동 복구되지는 않습니다.

## 실행 문제

| 증상 | 확인 |
|---|---|
| app.py 또는 requirements-ui.txt 없음 | 압축을 풀고 실제 파일이 있는 폴더에서 실행 |
| 패키지 오류 | 해당 환경에서 upgrade_ui_windows.bat 실행 |
| 토큰 만료 | 학교에서 새 토큰 발급 후 계정 설정 갱신 |
| 로그인 완료 후 대기 | 원래 Canvas 과목 탭으로 돌아가 계속 버튼 |
| 마이크 입력 없음 | Windows 입력 장치·권한·음소거 확인 |
| GPU 오류 | CPU나 더 작은 모델 선택 |
| 바로가기 실행 실패 | start_windows.bat로 오류 확인, 폴더 이동 시 바로가기 재생성 |

검증: 자동화 테스트 93개 통과. 실제 학교 계정, Windows 휴지통·바로가기·암호화, 물리 마이크·GPU 종단 간 실행은 제작 환경에서 검증하지 못했습니다. 플랫폼 문서: [Canvas](https://documentation.instructure.com/doc/api/index.html), [Qt 파일 처리](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QFile.html), [sounddevice](https://github.com/spatialaudio/python-sounddevice).
